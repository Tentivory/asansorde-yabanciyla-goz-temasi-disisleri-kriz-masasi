# Asansörde Yabancıyla Göz Teması Dışişleri Kriz Masası

> Kapalı kabin nötr bölge değildir. Nötr bölge, herkesin telefona bakmasıdır.

Bu kurum, asansör içinde gerçekleşen her bakışı, her öksürüğü ve her "günaydın"ı resmi dış ilişkiler evrakı sayar. Yazılım **gerçekten çalışır**. Çıktısı resmi tutanaktır. Tutanağın hukuki değeri sıfırdır; ciddiyet katsayısı yüksektir.

## Görev

1. Kabine giren ikinci kişiyi karşı heyet ilan etmek.
2. Göz temasını kriz seviyelerine ayırmak.
3. Aynı katta inmeyi ortak çıkar şüphesi kabul etmek.
4. Kapı açılınca herkesi kendi dış politikasına iade etmek.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. Diplomasi zaten yeterince ağırdır.

```bash
python3 kriz_masasi.py
```

Parametreyle (ciddi heyetler için):

```bash
python3 kriz_masasi.py --kat 7 --oteki-kat 7 --bakis "tam göz göze" --selam "günaydın"
```

## Kriz seviyeleri

| Seviye | Anlamı |
| --- | --- |
| KIRMIZI | Karşılıklı tanıma. Kapıdan sonra tekrar selamlaşmak nota ihlalidir. |
| TURUNCU | Sessiz tanıma. Telefona dönüş ateşkestir. |
| SARI | Aynı kat. Koridorda ikinci bakış yasaktır. |
| MAVİ | Ateşkes. Kabin nötr bölge ilan edilir. |
| YEŞİL | Rutin geçiş. Rapor arşive gider, kimse okumaz. |

## Anayasa maddesi (uydurma ama resmi duruşlu)

**Madde 1.** Asansör butonu oy değildir.  
**Madde 2.** Ayna, istihbarat değildir; yine de bakma.  
**Madde 3.** Köpekli heyetler önceliklidir, kuyruk protokoldür.
